## 一句话定义

索提诺比率只惩罚下跌波动，是"夏普比率的只怕跌版"，对正负波动不对称的策略更公平。

## 费曼讲解

夏普比率把"赚得猛"也算成风险——一家基金涨起来凶悍（比如重仓科技股的牛市行情），夏普分母被拉大，看起来"风险高"，其实你做梦都想要这种波动。索提诺的修正很直接：算波动时只统计低于目标收益（常用 0 或无风险利率）的日子，上涨日一律不计入分母。就像评估一个司机，只数他闯红灯和急刹车的次数，不因为他高速通过长直道而扣分。什么时候两者差距大？趋势策略：上涨月猛拉、下跌月克制，夏普平平、索提诺漂亮。什么时候两者接近？收益对称的配置型组合。看对冲基金报告时，若索提诺远高于夏普，说明它的收益靠"上涨斜率"而不是"抄底接飞刀"。

## 公式拆解

- σ下行（下行偏差）：只对低于 MAR（最低可接受收益）的样本求平方和的均值的根号
- MAR：目标收益，常用 0% 或 Rf；口径要在对比时统一
- 分子沿用 Rp − MAR
- 下行偏差用 N（全部样本数）而非只数下跌天数，保证跨策略可比

## 常见误用 / 红旗

- 误区 1：分母只除以"下跌天数"而非总样本数，索提诺被系统性高估
- 误区 2：同一篇报告里各策略的 MAR 口径不一致（一个取 0 一个取 Rf）

## 实战例子

策略年化 12%，月收益序列里上涨月平均 +4%、下跌月平均 −3%。全样本 σ=5% → 夏普 = (12−2)/5 = 2.0；只算低于 0 的月份，σ下行=3.1% → 索提诺 = 10/3.1 ≈ 3.2。比值 1.6 > 1 说明上涨贡献主导，收益质量好；若比值 < 1，警惕"靠扛深回撤换收益"。

## 卡壳点

卡在"下行偏差的分母为什么是全部 N"。突破点：如果只除以下跌次数，下跌越稀疏的策略分母越小、指标越高——"很少跌但一跌就 −20%"会被误判成安全；除以 N 等于把"频率×幅度"一起计价。
