# 这是一门什么生意

> 本篇是**示例笔记**，用于演示招股书类笔记的结构；请替换为你自己精读的招股书。

招股书第一节把公司讲成一个故事，但真正的信息在第三节以后。我的读法是倒着读：**先风险、再募资用途、最后故事**——故事是用来吸引你的，风险章节才是法律要求它必须说真话的地方。

# 为什么上市 / 募资用途

把募资用途逐条翻译成一句话："这钱花出去，几年后能变成什么资产？"如果答案是"补充流动资金"占大头，要警惕：上市融的钱不是用来做生意的，而是给老股东退出的。

# 商业模式拆解（第一性原理）

三个问题拆穿任何商业模式：

1. **谁付钱？** 客户≠用户≠付费者，三者分离时看谁的议价权大
2. **为什么是你？** 供应商能换、客户能换，公司卡在哪一环不可替换
3. **规模变大后更赚钱还是更亏钱？** 边际成本是否递减，决定这门生意值不值得上市放大

# 风险因素

- 风险章节里被写得最细的那条，往往就是管理层自己最怕的那条
- 与供应商/大客户的关联交易：把"利益输送"四个字写得更体面而已
